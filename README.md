GTVoidTech - HiTech addon for GregTech ceu 2.8.10 (1.12.2) Added new large machines and uhv+ tier content like Gregicality Legacy. 

The main goals of this addon are to break bedrock and collect Void Dust from beneath the world using a special machine, as well as to create an ultra-powerful alloy for a new reactor. 
Working with the new materials will require a Mass Spectrometer — a new multiblock structure. Progression in the mod will begin once you obtain the first ZPM processor. 

Work in progress!
